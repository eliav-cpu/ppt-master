# EXEL Agent Entrypoint - Read First

Status: Active

## Mandatory rule

Before creating any EXEL presentation, image, banner, social post, video script, landing page, website block, email, WhatsApp message, proposal or brand asset:

1. Read `EXEL-BRAND-OS/README.md`.
2. Read the active files in `01_BRAND_DNA/`.
3. Read the relevant production system for the requested asset.
4. Read the relevant QA checklist.
5. Use only approved EXEL assets and claims.
6. If a rule conflicts with an older chat instruction, the current GitHub source of truth wins unless the user explicitly changes the rule.

## Production law

The brand manages the tools. The tools do not manage the brand.

Every output must pass:

Source check -> Brand check -> Message check -> Visual/Text QA -> Approval status

## Separation law

PRIME / King Tamar and EXEL are separate brand systems.

PRIME / King Tamar can teach process architecture and QA discipline.
They cannot silently define EXEL's identity.
