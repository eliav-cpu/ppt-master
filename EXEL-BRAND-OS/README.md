# EXEL Brand Operating System

Status: Active Foundation
Owner: EXEL
Repository: eliav-cpu/ppt-master

## Purpose

This folder is the canonical Brand, Content, Visual and Presentation Operating System for EXEL.

It is intentionally separate from PRIME / King Tamar. PRIME materials may be used as process-learning references only; they do not define EXEL's brand language, colors, identity, positioning or visual system.

## Core public idea

EXEL = חוכמת הנדל״ן

Primary public-facing concept:

אדריכלות העסקה

Expanded form when context requires:

אדריכלות עסקאות נדל״ן

## Operating principle

Do not build a warehouse of tools.
Build a production line.

Request -> Source -> Brand DNA -> Message Architecture -> Visual System -> Production -> QA -> Approved Asset -> Learning Loop

## System layers

1. `00_SYSTEM/` - governance, entrypoint, source-of-truth rules, change control
2. `01_BRAND_DNA/` - positioning, identity, values, visual and verbal DNA
3. `02_VISUAL_SYSTEM/` - colors, typography, X motif, grids, cards, imagery, components
4. `03_PRESENTATION_SYSTEM/` - slide masters, presentation DNA, storytelling and QA
5. `04_CONTENT_SYSTEM/` - content pillars, social, video, landing pages, WhatsApp, email
6. `05_MESSAGE_LIBRARY/` - approved copy, headlines, hooks, claims, banned language
7. `06_PROMPTS/` - image, presentation, reverse-engineering and QA prompts
8. `07_TEMPLATES/` - reusable production templates
9. `08_REFERENCES/` - approved references and extracted lessons
10. `09_PROJECTS/` - project-specific systems that inherit EXEL DNA
11. `10_QA/` - visual, text, brand, content and preflight QA
12. `CHANGELOG.md` - DNA and system changes

## Source-of-truth rule

Any AI agent, design chat, NotebookLM workflow, Figma workflow, Canva workflow or presentation generator must read the EXEL entrypoint and active DNA before creating client-facing work.

Chat memory is not the source of truth.
GitHub is the source of truth.
